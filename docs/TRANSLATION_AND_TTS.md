# 翻译模式（英翻中 / 中翻英）与语音朗读（TTS）技术方案调研

关于**英汉双向翻译**与**语音朗读（TTS）**，在 Web 端与移动端（React Native）目前都有非常成熟、**完全免费**或**提供极高免费额度**的优质方案。

以下是技术实现方案的全面拆解与可行性分析：

---

### 一、语音朗读（TTS）：100% 免费且体验极佳（首推系统级原生）

语音朗读在 Web 和移动端其实**完全不需要购买云服务**，现代操作系统和浏览器原生内置了硬件级的语音合成引擎。

#### 1. Web 端：原生 `Web Speech API` (`window.speechSynthesis`)
* **费用**：**完全免费**，零依赖，不需要后端服务或 API Token。
* **音质表现**：
  * Chrome、Edge、Safari 原生自带高品质人声（例如 Edge 浏览器直接接入了微软云端的“晓晓/云希”等高拟真人声）。
* **功能支持**：
  * **中英双语**：通过 `voice.lang = 'zh-CN'` 和 `voice.lang = 'en-US'` 自动按语言匹配声线。
  * **高级控制**：天然支持语速调节（`rate`: 0.5x ~ 2.0x）、音调（`pitch`）、暂停/继续。
  * **朗读进度跟随**：通过 `onboundary` 事件可以精确拿到当前朗读的单词或字符下标，**实现类似歌词的“段落实时高亮”**。

#### 2. 移动端（React Native）：开源库 `react-native-tts`
* **费用**：**完全免费**，直接调用 Android 的 `TextToSpeech`（Google TTS/华为/小米系统语音）与 iOS 的 `AVSpeechSynthesizer`（Siri 人声）。
* **离线可用**：完全在本地设备运行，**不消耗手机流量**，响应速度毫秒级。
* **功能支持**：
  * 支持 `Tts.setDefaultLanguage('zh-CN')` 与 `Tts.setDefaultLanguage('en-US')` 无缝切换。
  * 支持播放队列、后台朗读、调节语速与语调。

---

### 二、文本翻译（英翻中 / 中翻英）：4 种免费路线对比

翻译需要处理长文本与术语，主要有以下 4 种无成本实现路线：

| 方案 | 技术路线 | 费用与额度 | 优点 | 缺点 / 限制 | 推荐指数 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **方案 1：免配置公共端点** | Google Translate 免鉴权端点 (`client=gtx`) | **完全免费**，无需注册 | 用户无需填写任何 Key，开箱即用，速度极快 | 若同一 IP 极端高频请求可能触发短暂 429 限流（个人单篇阅读完全不受影响） | ⭐⭐⭐⭐（适合默认兜底） |
| **方案 2：DeepL API Free** | DeepL 官方开发者免费版 | **每月 500,000 字符** 永久免费 | **翻译质量天花板**，长句、学术、技术文档极其地道，不生硬 | 用户需自行注册获取一个免费 Key | ⭐⭐⭐⭐⭐（技术阅读体验最佳） |
| **方案 3：大模型 LLM (Gemini / 智谱)** | Google Gemini Flash / 智谱 GLM | **官方免费并发额度**（每分钟 15 次调用） | 上下文理解强，可实现**术语对照**、**要点精读摘要** | 速度比专用机翻慢 1~2 秒 | ⭐⭐⭐⭐（适合全文智能总结） |
| **方案 4：端侧离线翻译** | Android Google ML Kit (`react-native-mlkit-translate`) | **完全免费**，离线模型（~30MB） | 100% 离线可用，隐私绝对安全，不耗流量 | 首次需下载语言包，翻译质量略逊于 DeepL/云端大模型 | ⭐⭐⭐（适合无网场景） |

### 三、如果落地到 GitFeed，最舒适的交互设计构想

如果后续要在 GitFeed 中引入这两项能力，推荐以下这种轻量、高颜值的交互形式：

1. **阅读器顶部新增「双语/翻译」按钮**：
   * **段落双语对照（推荐）**：保留原文，点击翻译后在英文段落下方渲染浅色译文，特别适合技术类 RSS 的学习与精读。
   * **一键整篇中英切换**：提供原文与译文的快速 Tab 切换。
2. **沉浸式朗读条（浮动播客化）**：
   * 点击「朗读」后，在屏幕底部浮现一个微型播放胶囊（显示当前阅读进度、播放/暂停、语速 `1.0x / 1.25x / 1.5x`）。
   * 朗读到哪一段，正文对应段落自动滚入视线并附带轻微的高亮底色。
3. **零成本默认 + 高级自定义**：
   * **默认开箱即用**：无需任何配置，自动使用免 Key 翻译端点 + 设备原生语音引擎。
   * **进阶用户（可选）**：可在设置里填入自己的 DeepL Free Key，享受极致流畅的专业级技术翻译。
